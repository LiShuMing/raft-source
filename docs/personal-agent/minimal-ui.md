# 极简界面迭代

后续设计见[产品设计 v0.2](product-design-v02.md)与[交互原型](prototype/index.html)。本文件仅记录上一轮配色/布局实现，不能作为完整产品设计。

2026-10-27。根据“整体不要黄色调，参考 Muse / Grok Bot 提供最简单界面”的反馈调整。

界面以对话为起点：一处目标输入、一个助理选择、一个发送动作。对话列表放在侧栏，任务与收藏是次级页面；设备、模型 API、工作空间和其他设置在需要时展开。保留真实执行位置，不把必要的运行状态变成装饰统计。

## 本轮变更

- 全局采用白、浅灰、黑色的语义主题，适配深色模式。替换 frame、sidebar、selection、brand 与浏览器/PWA 启动颜色，避免首次加载闪黄。主操作采用黑白对比，减轻按钮边框与字重，保留键盘焦点。
- standalone 主界面移除顶部工作空间条和图标轨道，使用一个简洁侧栏；最近对话直接读取已有 DM 与活动时间，切换工作空间回到对应个人首页。
- 首页减少重复标题、助理列表和常驻说明；设备与 API 配置收进“执行与连接”。小屏保留直接进入对话、任务和连接设置的入口。
- 任务页的频道/创建者/负责人筛选收进可展开区域，保留看板/列表切换、筛选提示与原有数据语义。
- 高级 Computer / 成员 / 设置页面继续使用现有业务组件；未改写执行协议、权限或任务范围。

## 验证

Web production build（含 TypeScript 与构建后检查）、组件 oxlint 与 color-token 检查通过。首页与导航行为 6 项、主题启动 9 项、任务页面 8 项测试通过。

浏览器检查包含浅色首页、深色首页、任务列表/看板切换、筛选展开、API 设置，以及 390×844 窄屏；窄屏文档宽度为 390，没有横向溢出。主按钮实际计算样式为中性深灰背景、白色文字。检查深色模式后已恢复原有“跟随系统”偏好。
