# v0.2 可点击产品原型

这是设计评审工具，使用预设对话与内存状态。无后端、模型调用、真实设备检测、授权或凭证保存，刷新会重置。秘密字段不可输入；附件是示例；导出生成带示例标识的Markdown。

在仓库根目录运行：

```sh
python3 -m http.server 5291 --bind 127.0.0.1 --directory docs/personal-agent
```

打开[交互原型](http://127.0.0.1:5291/prototype/index.html)。也可离线打开`index.html`，无CDN/字体依赖。

## 评审路径

1. 研究助理：编辑草稿→新动作版本→批准或拒绝→待处理更新。
2. 资料库：打开简报→版本与来源→保存技能→定时再做→时区/频率/三次日期→保存、暂停、历史。
3. 工作环境：接管→暂停状态→交还→离线→原设备恢复。
4. 助理资料：职责、记忆、技能、定时；更正或停用记忆。
5. 应用与连接：应用、Agent、API、设备；模拟检测，明确原生模式边界。
6. 新建：助理/工作组；搜索；切换对话后草稿独立保留。
7. 右上场景：首次使用、执行中补充、离线、成果审批。发送后用“推进演示”观察接收→执行→成果修订。

1130px以下检查区覆盖主区，700px以下侧栏收进菜单；支持深色与键盘路径。原型不能证明后端权限、真实恢复和调度可靠性。
